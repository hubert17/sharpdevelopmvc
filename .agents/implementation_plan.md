# Modernization Plan & Progress

This document tracks the modernization details and the phase-by-phase execution of porting the legacy SharpDevelop MVC 4 / Web API 2 application to a unified **.NET 10 MVC and Web API** project.

---

## 📅 Roadmap & Execution Phases

### [✓] Phase 1: Project Initialization & Core Security
*   **Project Structure:** Created a new .NET 10 Web App inside `Dotnet10MvcApi`.
*   **Home Routing:** Set up static file serving so that `/` serves `wwwroot/index.html` physically.
*   **Database Integration:** Configured EF Core using `EntityFrameworkCore.Jet` targeting the MS Access template `MyAccessDb.mdb`, designed dynamically for easy switching to **PostgreSQL** in the future.
*   **Centralized DB Authentication:** Replaced legacy CSV storage (`accounts.csv` and `refresh-tokens.csv`) with database-backed tables (`Users`, `RefreshTokens`) using PBKDF2 with HMAC-SHA512 password hashing.
*   **API Documentation Playground:** Integrated native OpenAPI generating tools and mapped a **Scalar** API visualizer and testing console served at `/scalar/v1`.
*   **JWT Token Operations:** Wrote endpoints `/TOKEN`, `/TOKENREFRESH`, `/TOKENLOGOUT`, and `/api/account/register` using a centralized JWT Token Manager.

### [✓] Phase 2: Core Models & API Controllers Port
*   **Data Models:** Ported `Product`, `Song`, and `WeatherForecast` models into the .NET 10 schema.
*   **Bulk Database Seeding:** Optimized the database initialization checks in `Program.cs` to seed 10,000+ Billboard records using raw ADO.NET SQL parameterized commands in a single transaction (completed in <2 seconds instead of minutes under EF Core change tracking).
*   **#Dual Table Initialization:** Configured `Program.cs` to check and seed the dummy `[#Dual]` table with 1 row on startup, satisfying the Access SQL requirements generated by the Jet provider.
*   **Helper Utilities:** Modernized [EmailService.cs](file:///c:/Users/Gabs/GitHub/hubert17/sharpdevelopmvc/Dotnet10MvcApi/Helpers/EmailService.cs) and [ImageUploadExtension.cs](file:///c:/Users/Gabs/GitHub/hubert17/sharpdevelopmvc/Dotnet10MvcApi/Helpers/ImageUploadExtension.cs) (with GDI+ image resizing and thumbnail optimizations saved to `wwwroot/UploadedImages/`).
*   **API Controller Ports:** Ported `SongController` and `SampleController` (e.g. weather feeds, secure product feeds, SMTP mail triggers, and multipart file uploads).

### [✓] Phase 3: MVC Controllers & Dual Authentication Setup
*   **MVC Controllers:** Ported `AccountController` (MVC forms logic, registration, change password, user list management, and user deactivation) and `CrudsampleController` (paged product listings, detailed views, and full CRUD creation/editing forms).
*   **Dual Authentication Support:** Configured the startup pipeline to register both Cookie Authentication (default scheme for server-rendered Razor MVC controllers) and JWT Bearer Authentication (explicitly targeted by API controllers via `[Authorize(AuthenticationSchemes = JwtBearerDefaults.AuthenticationScheme)]`).
*   **Redirections:** Created a legacy route redirect mapping `/swagger` to `/scalar/v1` and updated `index.html` links.

### [/] Phase 4: Razor Views Migration (In Progress)
*   **Razor Templates:** Copy and adjust MVC views (`.cshtml`) from `SharpDevelopMVC4/Views` (`Account`, `Crudsample`, `Home`, `Shared`, `WeatherForecast`) to ASP.NET Core views under `Dotnet10MvcApi/Views`.
*   **Modernization of Helpers:** Replace legacy ASP.NET 4.5 helpers (like `@Html.BeginForm` or `@Html.AntiForgeryToken`) with standard ASP.NET Core Tag Helpers (`asp-controller`, `asp-action`, `asp-validation-summary`).
*   **CSS Stylesheet Integration:** Port legacy styling rules and Bootstrap versions to `index.css` inside `wwwroot`.

### [ ] Phase 5: Vue.js Integration & Final End-to-End Verification
*   **Vue Client:** Embed a no-build, no-node Vue.js application inside `wwwroot/index.html`.
*   **API Consuming:** Connect Vue.js components to fetch JWT tokens, list songs with pagination, and interact with the REST endpoints securely.
*   **Final Verification:** Build and run under x64 emulation, testing end-to-end authentication, database transactions, image uploads, and page rendering.
